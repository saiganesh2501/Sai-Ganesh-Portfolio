# Sai Ganesh Nelluri Portfolio

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Upload this folder to GitHub.
2. Go to Vercel and import the GitHub repository.
3. Keep framework as Vite.
4. Click Deploy.

## Important files

- `src/App.jsx` contains the portfolio content.
- `public/ganesh_picture_.png` is the hero portrait.
- `public/profile_pic_corporate.jpg` is the about section photo.
- `public/Sai_Ganesh_Nelluri_Resume.docx` is the resume download file.
